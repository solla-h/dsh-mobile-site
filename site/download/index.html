DSH Mobile App APK 下载

DSH Mobile App 是配套 DeepSeek Harness（DSH）的第三方开源安卓客户端，让你在手机上查看会话进度、处理审批与提问、继续对话。APK 的唯一分发入口是 App 仓库的 GitHub Releases，本站不托管安装文件、不提供镜像，也不收集下载信息。当前为 Android 公开 alpha 的预发布版本，需要侧载安装；与 DeepSeek 官方无关联。

下载前，一眼看清

当前分发状态

这些边界不会随某个 Release 页面改版而消失，先看清再下载。

平台
当前仅 Android。iOS 暂缓且未验证；没有在所有 Android 机型上验证过，安装下限不等于兼容性承诺。
发布阶段
公开 alpha，预发布（prerelease）。协议与界面仍在演进，不能当作稳定版；本站不写死某个 APK 文件名，也不使用 /releases/latest 跳转，请打开 Releases 页面看当前版本。
分发方式
侧载安装，没有应用商店版本，也没有本站镜像。APK 体积较大，App 仓库的部署说明因此把它保留在 Releases 而不是官网。
运行前提
App 不是独立聊天工具：需要一台运行 DSH Web 的宿主、配套手机网关插件、锁定的版本组合，以及手机到网关的网络路径。Agent 与模型留在宿主上，手机不运行模型。
许可
App 原创代码采用 MIT；宠物动画素材采用 CC BY-NC-SA 4.0，仅限非商业使用。详见 Release 页面附带的许可文件与 NOTICE。

版本与发布状态以 GitHub Releases 与 App 仓库当前文件为准；发版信息不靠记忆补。

下载步骤

四步，别跳步

下载本身只占一步，其余三步决定你能不能真的连上。

  1. 先对齐版本组合

    打开 compatibility.json，确认当前锁定的 App、网关插件与 DSH 版本。宿主版本不一致时停下核对，不要靠升级 APK 去「碰」一个能用的组合。详见版本兼容说明。

    compatibility.json 版本兼容说明

  2. 在 Releases 取当前版本

    打开 GitHub Releases，在当前版本的 Assets 中取签名 APK；同一页面提供校验文件、构建信息与许可文件，一并核对。不要从第三方镜像或转存下载，也不要写死某个文件名。

    打开 GitHub Releases

  3. 校验后侧载安装

    按 Release 页面提供的校验文件核对下载结果，再在 Android 上允许浏览器或文件管理器的安装。升级时直接覆盖安装，不要先卸载，以保留配对记录、会话草稿与发件箱。

装好之后

还需要宿主侧生成的一次性配对码才能连接；配对码短时有效，请当密码对待。公网入口必须使用 wss://，App 拒绝明文 ws://。二维码、设备凭据与真实主机地址不要贴进公开 issue 或截图。

下载相关疑问

最常见三个问题

能用 /releases/latest 或直接固定文件名吗？

不建议，本站也不这么做。当前版本是预发布，文件名与 tag 会随发布变化；请打开 Releases 页面按当前版本选择，并使用同页的校验文件核对。

官网为什么不直接放 APK？

APK 由 App 仓库的发布流水线构建与签名，Releases 是唯一可核对来源；本站是静态介绍站，不托管安装文件、不提供镜像，也不统计下载完成或安装结果。这样下载来源、校验与签名证据都集中在一处。

下载失败或安装被拦住怎么办？

先确认网络与浏览器/文件管理器的安装权限，再核对文件是否完整；仍不行请到 GitHub Issues 附上 App、网关与 DSH 版本和复现步骤。更多边界见常见问题。

能做什么

手机上，只做三件事。

它不是一个缩小的桌面页面。离开电脑的时候，你通常只想知道进展、做个决定，或者补一句话。

  1. 01看一眼

    什么在跑，什么在等你。

    聚焦页把需要你出手的会话排在最前：有待处理审批或提问的在先，其次是运行中的，最后是最近聊过的。手上有几台宿主，就从顶部在几个网关之间切换。

  2. 02拍个板

    审批与提问，就地决定。

    审批卡给出真实的命令、目标文件和可用的 diff，而不只是一句摘要。高风险操作需要按住约半秒确认，拍板后还有几秒可以撤回。Agent 的提问可以选一项，也可以直接写回答。

    App 不会替你自动批准任何东西。审批决定必须在线发送。

  3. 03说一句

    接着说，打字或按住说话。

    回复流式到达，思考与工具调用折叠成一组，需要时再展开。Agent 还在跑时，可以把消息排队到这一轮之后，也可以插话，让它在下一步就看到。可以附上图片和文件，也可以随时停止当前回合。

    按住说话需要宿主安装匹配的语音插件，并准备好识别模型；识别在宿主侧完成，手机本地不做识别。

细节与前提

能做到的，和它需要的。

每一项能力都有边界。我们把条件写在旁边，而不是藏进脚注。

可以前提与限制

  • 离开再回来，列表和草稿都还在

    前提会话列表、草稿和附件信息缓存在手机上。离线时写的文字进入发件箱，重连后按顺序发出；附件上传和审批决定必须在线。

  • 在多个网关之间切换

    前提每个网关单独扫码配对，各自保存会话、草稿和发件箱；手机需要能访问对应的网关入口。

  • 入口地址变了，也能找回网关

    前提可选的加密地址簿，需要支持它的网关和你自己的 Cloudflare 账号，恢复通常要一到三分钟。它只加密入口地址，不等于会话端到端加密，也不是使用前提。

  • 回到 App 时自动重连

    前提进入后台后系统会挂起 App，回到前台时再探活重连。当前版本不提供系统推送通知，也不保证后台常驻。

  • 在手机上管理宿主的插件

    前提管理的是网关背后 DSH profile 的插件。关闭或卸载手机网关本身会立即断开连接，只能回到宿主上恢复。

开始使用

三步，连上你的宿主。

这里只画路线。具体命令和锁定版本以 App 仓库的文档为准，它们会随版本更新。

  1. 准备好 DSH 宿主

    一台持续运行 DSH Web 的电脑或服务器。DSH Mobile 不自带模型，也不托管任何服务，Agent 始终在这台机器上执行。

    查看版本兼容

  2. 安装手机网关，生成配对码

    在对应 profile 安装 dsh-plugin-mobile-gateway，版本须与 App 锁定的组合一致。配对码一次性、约五分钟有效，请像对待密码一样对待它。也可以把 Agent 安装手册交给你的 DSH 代办。

    中文使用说明 Agent 安装手册

  3. 安装 APK，扫码连接

    从 GitHub Releases 下载 APK 并允许安装；同页附有校验文件。打开 App 扫描配对码，或手动粘贴配对串。以后升级直接覆盖安装，不要先卸载。

网络要通

手机需要能访问网关：同一 Wi-Fi 下直连，或经由 Cloudflare Tunnel、Tailscale 等入口。公网入口必须使用 wss://。

常见问题

开始之前，你可能想问。

这是 DeepSeek 官方的 App 吗？

不是。DSH Mobile 是独立的第三方开源项目，与 DeepSeek、Expo 官方均无关联。

我需要准备什么？

一台运行 DSH Web 的宿主、装在对应 profile 里的手机网关插件、一台 Android 手机，以及手机到网关的网络路径。

DSH 与网关的版本必须和 App 锁定的组合一致，见 compatibility.json。

模型会在手机上运行吗？

不会。Agent 在你的宿主上运行，手机只是客户端。它也不是托管的 AI 服务。

语音输入需要什么条件？

宿主需要安装与 DSH 版本匹配的语音插件，并且识别模型已经就绪。模型没准备好时，App 会明确显示「语音未启用」，不会静默失败。

断线了会怎样？

App 会自动重连，点顶部的连接提示可以立即重试。离线时写的文字进入发件箱，重连后按顺序补发。

断线瞬间仍在途的消息可能显示「未确认」，App 不会静默重发，需要你手动重试。设备被撤销或凭据过期时，需要重新配对。

有 iOS 版吗？能在应用商店下载吗？

目前都没有。iOS 版暂缓，尚未验证；Android 版通过 GitHub Releases 侧载安装，也没有在所有机型上验证过。

现在的版本稳定吗？

不算稳定，这是公开 alpha，协议和界面仍在演进。当前可下载的版本、校验文件和已验证范围，请以 Releases 和 App 仓库的说明为准。

我的数据存在哪里？

配对凭据保存在手机的安全存储里；会话历史、草稿和附件信息缓存在手机本地。App 没有接入第三方分析 SDK，但宿主、网关和你使用的隧道服务可能各自保留日志。

手机丢失时，请到网关面板撤销这台设备；只在另一台手机上移除网关并不会撤销它。

采用什么开源许可？

App 原创代码采用 MIT；App 里的宠物动画素材采用 CC BY-NC-SA 4.0，仅限非商业使用。详见 LICENSE 与 NOTICE。本网站内容采用 MIT，没有使用这些素材。

遇到问题去哪里反馈？

请到 GitHub Issues，附上 App、网关和 DSH 的版本与复现步骤。不要贴配对二维码、设备凭据或未打码的会话截图。

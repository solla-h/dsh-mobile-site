DSH Mobile 是第三方、开源的 DeepSeek Harness（DSH）Android 客户端， 连接用户自己运行的 DSH 宿主。当前为 Android 公开 alpha，通过 GitHub Releases 侧载安装；iOS 暂缓。

获取 Android APK 安装与配对指南

开始前需要知道

  • App 不自带模型，也不托管 DSH；需要一台运行 DSH Web 的宿主，并在对应 profile 安装 dsh-plugin-mobile-gateway。
  • 本版本锁定 DSH 0.2.1-rc.5 + 网关 0.12.0-rdv.3，见 compatibility.json。
  • 语音是可选能力，需要宿主安装匹配的插件并准备好识别模型。

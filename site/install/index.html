DSH Mobile App 安装与配对教程

本页把「从零连上自己的 DeepSeek Harness 宿主」拆成可核对的三步：先在宿主侧锁定版本并安装手机网关，再由宿主生成一次性配对码，最后在 Android 手机上侧载 DSH Mobile App 并扫码。DSH Mobile App 是第三方开源 Android 客户端，Agent 始终运行在你自己的宿主上；本页只讲顺序与前提，具体命令和当前锁定版本以 App 仓库文档为准。

开始之前

先确认这四件事

跳过前提最常见的结果是「装好了但连不上」。下面每一项都能在动手前核实。

一台运行中的 DSH 宿主
一台能持续运行 DSH Web 的电脑或服务器，并且已经能在 DSH Web 里完成一次正常对话。DSH Mobile App 不自带模型，也不托管服务；宿主停机时手机无法继续跟进 Agent。
宿主侧工具链
需要 Node.js 22.13+、npm、Git，以及 PATH 上的 pnpm；App 仓库的安装说明把 pnpm 锁定为 11.9.0。可先用只读的 pnpm --version 确认，缺失时在普通终端安装，不要用升级 DSH 来绕过。
锁定的版本组合
App、网关插件、DSH 与语音包各自独立演进，必须按 compatibility.json 的 recommended 精确匹配。版本不一致时策略是「停下来询问」，不是自动升级或试一试。详见版本兼容说明。
手机到网关的网络路径
同一 Wi-Fi 直连，或经 Cloudflare Tunnel、Tailscale 等入口；公网入口必须使用 wss://，App 拒绝明文 ws://。当前仅 Android 公开 alpha，无应用商店版本，iOS 暂缓且未验证。

事实来源：Agent 安装手册、中文使用说明、compatibility.json 与 GitHub Releases。

动手顺序

三步，按这个顺序来

顺序不是建议：宿主侧必须先就绪，手机才有可扫的配对码。

  1. 核对版本，再动宿主

    打开 App 仓库的 compatibility.json 和兼容说明，记下当前锁定的 App、协议、网关插件、DSH 与可选语音包版本。只使用 recommended 中的值：不要用 @latest、本地 git clone、link: 依赖或 profile 备份，也不要把上游插件和本项目维护的 fork 同时装上。

    compatibility.json 版本兼容说明

  2. 在宿主装网关，生成配对码

    按 Agent 安装手册，先执行 handoff 生成 DSH-MOBILE-NEXT-STEPS.md，把文件路径和完整命令一起交给人，然后才运行带 --stop-web --restart-web --tunnel quick --pair --open 的安装命令。它会在普通终端里安装锁定版本的网关、重启 DSH Web、开启临时入口并打开配对页；用户只需扫码。不要在 DSH Web 会话内执行停止命令，也不要把「先停服务」当成第一步。

    Agent 安装手册 中文使用说明

  3. 侧载 APK，扫码连接

    从 GitHub Releases 当前版本的 Assets 取签名 APK，按页面提供的校验文件核对后允许安装，不要写死某个 APK 文件名或使用 /releases/latest。打开 App 扫描配对码，或手动粘贴配对串。配对码一次性和短时有效，请像密码一样对待；公网入口必须是 wss://。升级时直接覆盖安装，不要先卸载，以保留配对记录与草稿。

    APK 下载页与校验说明 打开 GitHub Releases
配对之后

每个网关都要单独扫码配对，各自保存会话、草稿和发件箱。重启 DSH Web 后回到原来的会话列表重新打开原会话即可，不必新建任务。若手机丢失，到网关面板撤销该设备；只在另一台手机上移除网关不会撤销它。

排查

连不上时，按层往下看

先分清是网络不通、版本不匹配，还是设备被撤销；不要一上来就重装 APK。

扫码后一直连不上？

依次检查：手机能否访问网关入口（同一 Wi-Fi、隧道或 Tailscale）；公网入口是否为 wss://；宿主上的 DSH Web 与网关是否仍在运行；网关插件版本与 profile 是否与锁定组合一致。网络层通了再看应用层，能省掉大部分无效重装。

提示版本不匹配，能先升级试试吗？

不能自动升级任一侧。兼容策略要求精确匹配，不匹配时停下来核对 compatibility.json，确认该组合是否在已验证范围内；「未覆盖」的含义是停下来询问，而不是试一试。详见版本兼容说明。

语音按钮没反应？

语音是宿主侧的可选附加能力，不是网关协议的一部分。需要安装与 DSH 版本匹配的语音插件包并备好识别模型；模型未就绪时 App 会明确显示语音不可用，不会静默失败。识别在宿主侧完成，手机本地不做识别。

配对码过期或设备被撤销了？

配对码一次性、短时有效，过期就在宿主侧重新生成；二维码、配对串、设备凭据和真实主机地址不要贴进公开 issue 或截图。设备被撤销或凭据过期时，App 会停止重连，需要重新配对。

断网时写的消息会丢吗？

会话列表、草稿与附件信息缓存在手机上，离线时写的文字进入发件箱，重连后按顺序补发；发送与执行仍需恢复连接，附件上传和审批决定必须在线。断线瞬间在途的消息可能显示「未确认」，需要手动重试。更多边界见常见问题。
